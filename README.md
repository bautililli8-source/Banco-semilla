# Banco de Semillas

Página pública del Banco de Semillas de la escuela agropecuaria.

Se puede abrir desde cualquier celular o computadora, sin cuenta. Los alumnos ven el catálogo de semillas y, en «Llevar / devolver», arman un comprobante que le mandan al docente por WhatsApp.

Esta es una copia del banco en un momento dado: para mostrar datos nuevos hay que volver a subir `index.html`.
